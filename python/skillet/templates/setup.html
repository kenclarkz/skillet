🍳 Skillet needs a Supabase connection

This app talks to a Supabase project for its database, auth, and photo storage. Set two environment variables and reload.

SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your-anon-key
  1. Create a free project at supabase.com.
  2. Open the SQL Editor and run supabase/migrations/20261017000001_init.sql from this repo.
  3. Copy the project URL and anon key from Settings → API into the environment (.env next to wsgi.py on PythonAnywhere, or the “Env vars” section of your web app).
  4. Reload the web app and sign up.

See python/README.md for the full step-by-step PythonAnywhere guide.
