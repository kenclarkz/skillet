Import from your browser

Some recipe sites (HelloFresh included) block servers from fetching their pages. With browser import, your own browser reads the recipe from a page you have open and sends the extracted data to Skillet — the server never contacts the source site, and nothing is submitted to it either.

Set up once

  1. Right-click your bookmarks bar and choose Add page… (or press Ctrl/Cmd+D).
  2. Name the bookmark Skillet Import.
  3. Paste the code below into the bookmark's URL / Address field.

Use it

  1. Open a recipe page in your browser.
  2. Click the Skillet Import bookmark.
  3. Review the editable preview in the new tab, adjust anything, then save.

If the bookmark shows "could not find a recipe" (a few sites restrict what bookmarks may run), save the page as a PDF and use Import Recipe PDF, or paste the text there.
